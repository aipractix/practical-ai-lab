
# Practical AI Lab

**Learn. Experiment. Build Practical AI.**

Practical AI Lab is an open collection of AI tutorials, experiments, and engineering examples maintained by the [AIPractix](https://aipractix.com) team.

Our goal is to share practical knowledge, reproducible code, and real-world engineering insights to help developers turn AI ideas into working solutions.

## Topics

- **Computer Vision** — Image processing, detection, recognition, tracking, and more.
- **Deep Learning** — Model training, inference, evaluation, and optimization.
- **Edge AI** — ONNX, NCNN, mobile inference, and efficient deployment.
- **Generative AI** — LLMs, multimodal AI, and practical applications.
- **AI Applications** — End-to-end examples and real-world use cases.

## Repository Structure

```text
practical-ai-lab/
├── computer-vision/
├── deep-learning/
├── edge-ai/
├── generative-ai/
└── applications/
```

Each example may include source code, setup instructions, sample data, and links to related technical articles.

## Getting Started

Browse the topics above and explore an example that interests you. Each example will provide its own instructions and dependencies where applicable.
